# Markdown Editor 示例文档

欢迎！这是一个可以直接在编辑器里打开体验的示例文档。把 `examples/` 文件夹作为工作区打开，就能试用文件树、全文搜索、标签索引和反向链接。

> 编辑方式接近 Typora：正文保持排版后的样子，只有光标所在的段落会露出 Markdown 标记。

**粗体**、*斜体*、`行内代码`，以及 ==高亮文本==。上标如 x<sup>2</sup>，下标如 H<sub>2</sub>O。

## 试试这些操作

1. 按 `Ctrl+F` 查找「Markdown」，体验高亮与替换。
2. 在「视图」菜单里增减侧栏面板，勾选状态会同步。
3. 在「外观」菜单里切换深色主题、专注模式、打字机模式或拼写检查。
4. 点击 `[[关联笔记]]` 跳转，再从反链面板看它如何指回本文。
5. 用「文件 → 导出」生成 HTML 或 PDF，目录锚点会保持一致。
